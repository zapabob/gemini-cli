## 利用可能な機能

### 基本コマンド
- `gemini` - インタラクティブCLIを起動
- `gemini -p "プロンプト"` - 非インタラクティブモード
- `gemini -i "プロンプト"` - プロンプト実行後インタラクティブ継続

### 主要オプション
- `-m, --model` - モデル指定 (デフォルト: gemini-2.5-pro)
- `-s, --sandbox` - サンドボックスモード
- `-d, --debug` - デバッグモード
- `-a, --all-files` - 全ファイルをコンテキストに含める
- `-y, --yolo` - 自動アクション承認モード
- `-c, --checkpointing` - ファイル編集のチェックポイント有効化

### 拡張機能
- `-e, --extensions` - 使用する拡張機能指定
- `-l, --list-extensions` - 利用可能な拡張機能一覧
- `--ide-mode` - IDEモード実行
- `--experimental-acp` - ACPモード起動
