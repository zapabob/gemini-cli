## 技術的特徴

### 🤖 メインエージェント機能
- **タスク分析**: 複雑度、必要専門分野、推定時間の自動分析
- **サブエージェント選択**: スコアリングシステムによる最適なサブエージェント選択
- **結果統合・検証**: 複数サブエージェントの結果を統合・品質評価
- **推奨事項生成**: 失敗・遅延タスクの自動検出と推奨事項

### 🔄 リアルタイム協調実行
- **協調セッション**: リアルタイムでのメインエージェントとサブエージェントの協調
- **動的アクション決定**: 状況に応じた次のアクションの自動決定
- **ステップ管理**: 実行ステップの詳細追跡・記録
- **メトリクス収集**: 実行時間、成功率、トークン使用量の詳細分析

### 📊 高度なスコアリングシステム
- **成功率スコア**: 過去のタスク実行履歴に基づく成功率評価
- **専門性スコア**: タスク要件とサブエージェント専門分野の適合度
- **最近性スコア**: 最近の使用頻度による活性度評価
- **設定スコア**: 温度設定などのパラメータによる調整

### 🛡️ 電源断保護機能
- **自動チェックポイント**: 5分間隔での定期保存
- **緊急保存**: Ctrl+C や異常終了時の自動保存
- **バックアップローテーション**: 最大10個のバックアップ自動管理
- **セッション管理**: 固有IDでの完全なセッション追跡

## 使用方法

### 基本コマンド
```bash
# 協調タスク実行
/collaborative execute "複雑なコードレビューを実行してください"

# リアルタイム協調実行
/collaborative realtime "リアルタイムでデバッグを支援してください"

# タスク分析
/collaborative analyze "このプロジェクトの分析を行ってください"

# システム状態表示
/collaborative status
```
